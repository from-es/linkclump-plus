About

This page verifies Linkclump Plus's behavior with dynamically added/removed links, as well as live link detection during asynchronous loading and infinite scrolling.

Dynamic DOM Principle:

Linkclump Plus scans document.links fresh on each selection start. Dynamically inserted links are detected immediately on the next drag without requiring a page reload. Removed links are evicted from detection.

Procedure & Expected Results

  1. Click "Add Link" a few times, then drag-select across the newly added links.
  2. Click "Remove Last Link" and verify the removed link is no longer selectable.
  3. Enable "Infinite Scroll", scroll down to trigger dynamic loading, and verify newly loaded links are selected.
Action / Scenario Drag Selection Target Expected Result
Initial Links Dynamic Link 1 to 3 Selected links are detected and opened.
Add Link Newly appended links Newly created links are immediately selectable on next drag.
Remove Link Area of removed link Only remaining links are selected; removed links are ignored.
Infinite Scroll Auto-loaded links at page bottom Asynchronous links appended while scrolling are detected once rendered.
