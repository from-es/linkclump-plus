Click After Release Test

About

This page is a test page to verify that Linkclump Plus does not activate a link by itself when a selection is released.

While a selection is dragged, Linkclump Plus captures the pointer on the element the press started on. Browsers then send the click that follows the release to that element, so a selection that starts on a link used to activate that link natively: the original tab navigates, a target="_blank" link opens an extra tab, and releasing with Ctrl held opens an extra background tab. A selection that starts outside every link was never affected.

Procedure

  1. Set the action to Opened as New Tabs (default: key Z + left mouse button). Repeat with Ctrl as the key if you like.
  2. Hold the key, press the mouse button at the Start position, drag over the links, and release at the End position of each row below.
  3. Compare the result with Expected. Outside means the grey area to the right of the links (or the white area around the list).
  4. Reload this page between rows if it navigated.

Click Monitor
