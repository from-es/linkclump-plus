Linkclump Plus: Frame & iframe Selection Test

Return to Test Page Index

About

This page verifies the behavior of Linkclump Plus when selecting links within and around various frame environments:

  • same-origin <iframe>s
  • cross-origin <iframe>s
  • nested <iframe>s (multi-level)
  • scrollable <iframe>s
  • inline srcdoc <iframe>s
  • classic HTML <frameset> / <frame>
Core Specification / Boundary Principle:
  • Single Frame Boundary: Link selection and the drag bounding box are strictly confined to the frame (top page or specific <iframe>) where the pointer press and drag gesture began.
  • No Cross-Boundary Selection: Dragging starting from the parent page cannot capture links embedded inside an <iframe>. Conversely, dragging starting inside an <iframe> cannot select parent page links or sibling frame links.
  • Overlay Clipping: The visual selection box rendered by Linkclump Plus is contained within the initiating frame's DOM and will not render outside that frame's viewport.

Procedure & Expected Results

Hold the configured key, then press and drag the mouse button across the target area. Release the button to open the selected links.

Test Case Drag Start Drag Over / Release Expected Result
Top Document Selection Parent page background or link Parent page links Only parent page links are highlighted and opened.
Parent Drag Over <iframe> Parent page Passes over or releases inside an <iframe> Only parent links are selected. Links inside the <iframe> are completely ignored.
Same-Origin <iframe> Inside <iframe> Inside <iframe> links Links inside the <iframe> are selected. Parent links are NOT selected. Selection box stays inside the <iframe>.
Cross-Origin <iframe> Inside external <iframe> Inside external <iframe> links Content script in external <iframe> handles selection within its frame boundaries.
Nested <iframe> (Lv1 vs Lv2) Inside Level 1 <iframe> Passing over Level 2 <iframe> Only Level 1 links are selected. Level 2 (grandchild) links are NOT selected.
Nested <iframe> (Lv2) Inside Level 2 <iframe> Inside Level 2 links Only Level 2 links are selected. Level 1 links are NOT selected.
Scrollable <iframe> Inside scrolled <iframe> Scrolled links Selection box and link coordinates accurately track the scrolled viewport position.
srcdoc <iframe> Inside srcdoc <iframe> Inside srcdoc links Linkclump Plus does not run inside about:srcdoc (stability & security constraints). A drag inside has no effect (native browser behavior applies). Dragging from the parent page over the frame selects only parent links.
Classic <frameset> Inside Left or Right <frame> Links within that <frame> Each <frame> operates independently as an isolated document boundary.
