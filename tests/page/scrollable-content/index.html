About

This page systematically verifies Linkclump Plus's behavior across three distinct scrolling contexts: internal CSS scroll containers (overflow: auto), scrollable <iframe>s, and top-level page window scrolling.

Implementation Behavior & Constraints:
  • Coordinate Compensation: Linkclump Plus traverses parent scroll containers in getXY() and subtracts scrollLeft and scrollTop, ensuring accurate hit-testing for links visible at their current scroll position.
  • Auto-scroll Boundary Principle: Auto-scroll operates by checking whether the pointer is near a window viewport edge (window.innerHeight - 20) and invoking window.scrollBy():
    • CSS Scroll Container (overflow: auto): As a DOM element rather than a window, dragging to the boundary of an internal container will not auto-scroll the container (known implementation constraint).
    • Top-level Window: Dragging near the top or bottom edge of the browser viewport auto-scrolls the entire document.
    • Scrollable <iframe>: Because each frame runs an independent content script in its own window context, dragging that starts inside the iframe will auto-scroll the iframe when reaching the frame's viewport edge.

Procedure & Expected Results

Hold the configured key, then press and drag the mouse button across the target areas described below.

Context / Scenario Operation Expected Selection & Scroll Behavior
Case 1: CSS Container (Visible) Drag-select visible links (Link 1 to 5) Visible links are highlighted and selected normally.
Case 1: CSS Container (Scrolled) Manually scroll down, then drag-select Scroll offset is accurately compensated; newly visible links (e.g. Link 6 to 10) are selected.
Case 1: CSS Container (Edge Drag) Drag towards bottom/top boundary of container No Auto-scroll: Container does not auto-scroll (known constraint: auto-scroll only targets window).
Case 2: Scrollable <iframe> Drag starting inside iframe towards bottom edge Auto-scrolls iframe: Child frame's window auto-scrolls, revealing and selecting deeper links.
Case 2: Scrollable <iframe> Drag starting outside iframe across boundary No Selection / No Scroll: Selection does not cross frame boundary; child iframe does not scroll.
Case 3: Window Viewport Drag towards browser window bottom edge Auto-scrolls page: Top-level document scrolls up/down via window.scrollBy().
