CSS Transform Link Selection Test

Return to Test Page Index

About

This page verifies Linkclump Plus's link selection function within elements to which CSS transform properties (translation, rotation, and scaling) are applied.

Transform Support & Architectural Insights:
  • Translation (translate): Supported. Linkclump Plus parses DOMMatrix in getXY() to account for matrix.m41 and matrix.m42 translation values.
  • Rotation & Scaling (rotate, scale): Current specification treats links as axis-aligned bounding rectangles. Rotated non-orthogonal elements may exhibit hit-test variance.
  • Future Architecture Proposal: Rather than superimposing absolute overlay box elements over transformed geometry, future versions may dynamically attach CSS classes directly to matching link elements and render highlights via CSS outline or box-shadow, seamlessly supporting arbitrary 2D/3D transforms, irregular polygons, and dynamic animations.

Procedure & Expected Results

  1. For each test case below, drag-select across the links in their default (untransformed) state and verify all links are selected normally.
  2. Check the "Toggle Style" checkbox to apply the CSS transform (and related) properties for that case.
  3. Drag-select the same links again and compare results with the expected behavior below.
Transform Type Implementation Scope Expected Result
CSS Translation (translate(X, Y)) Full Support Selected at visually shifted position (tracked via m41, m42).
Combined Offset & Transform Full Support Both top/left offsets and translate() are compounded correctly.
Rotational & Circular Layouts (rotate()) Specification Boundary Hit-testing follows translation centers; extreme angle rotations may select per axis-aligned bounds.
