About

This page verifies Linkclump Plus's link selection function within elements to which basic CSS layout properties (margin, padding, width constraints, positioning) are applied.

Known Historical Precaution:

Pages with fixed body width and margin: 0 auto can shift cursor coordinate mapping relative to document bounds. This page allows testing combinations of body constraints and container positions.

Procedure & Expected Results

  1. Select style options below to apply CSS properties to body or #linklist-container.
  2. Hold the configured key and drag-select across the "Target Link List".
  3. Verify that Linkclump Plus's selection box and detected link highlights align accurately with the target links.
Applied Style Property Target Element Expected Result
margin: 3rem; / padding: 3rem; body Offset added to body is correctly accounted for; links are selected at their visual positions.
width: 1280px; margin: 0 auto; body Centered body bounds align with viewport; selection box tracks pointer without horizontal drift.
position: relative / absolute #linklist-container Repositioned container links are accurately hit-tested at their shifted coordinates.
position: fixed / sticky #linklist-container Links staying in viewport during scroll are detected at current viewport offset.

Default Page Style

This is the baseline CSS applied before options below are selected:

:root {
	--font-size-base: 16px;
}

html, body {
	margin : 0;
	padding: 0;
}

html {
	font-size: var(--font-size-base);
}

main {
	margin: 0;
	padding: 0;
}
