  • https://example.com/ — Recommended. Blocks this site and all pages under it, avoiding unintended matches on other domains.
  • https://mail.google.com/ — Blocks only this specific subdomain.
  • https://example.com/editor/ — Blocks only pages under /editor/ (the rest of the site remains active).
  • example.com — Blocks the domain and all subdomains, but may also match other sites (e.g. notexample.com). Do not use wildcards (e.g. *.example.com).

FAQ

Linkclump Plus isn't working.
  • Make sure you are pressing the correct mouse button and key combination.
  • Linkclump Plus doesn't work on browser internal pages (such as chrome:// or about: pages), extension store pages, or other browser-restricted pages.
  • On file:// pages, you must first allow access to local files (see the "To use on local pages" in this FAQ).
Link selection doesn't work with my laptop's built-in trackpad.

On Windows and Linux, pressing a letter key (such as the default Z) temporarily disables the built-in trackpad — this is an OS feature, not a bug in Linkclump Plus.

Solution: On the Options page, change the key of the Action from a letter key to a modifier key: Ctrl, Shift, or Alt (Windows only). An external mouse is not affected.

Why can't I set right-click without a key on macOS or Linux?

On macOS and Linux, the browser opens the right-click menu when you press the mouse button, before Linkclump Plus can tell whether you are dragging. Without a key, Linkclump Plus would have to block the menu on every right-click.

Solution: Always combine right-click with a key such as Shift, Ctrl, or Cmd (macOS). On Windows, right-click without a key is possible but is not recommended.

Can I use Linkclump Plus on a touch screen?

Yes. Press and hold for about 0.5 seconds, then drag to draw the selection box. The Action set to the Left mouse button runs when you release.

If you move your finger more than about 8 px before the hold is recognized, the page scrolls as usual instead.

To use on local pages (i.e. file:// URLs)

To use Linkclump Plus on URLs beginning with "file://", allow access to local files.

  • Google Chrome & Chromium-based browsers
    1. Open "chrome://extensions" in the address bar.
    2. Click Details for Linkclump Plus.
    3. Turn on Allow access to file URLs.
  • Mozilla Firefox & Firefox-based browsers
    • version 153 and later
      1. Open "about:addons" in the address bar.
      2. Select Manage from the Linkclump Plus menu.
      3. Select Permissions and data.
      4. Turn on Access local files on your computer.
    • Version 152 or earlier
      1. Open "about:addons" in the address bar.
      2. Select Manage from the Linkclump Plus menu.
      3. Select Permissions and data.
      4. Turn on Access your data for all websites.
Tabs open twice, or two counters appear when I select links.
Another extension that does the same job is running at the same time. If the original Linkclump or Snap Links Lite is installed and enabled, both extensions react to the same drag. Turn off or remove the other extension.
The auto-close timer (close tab time) doesn't always close tabs.

The timer runs in the extension's background process. The browser can stop that process while it is idle, which cancels any pending timers before they fire.

Recommendation: Keep close tab time and delay in opening values short — 20 seconds or less.

The selection box and the cursor are misaligned on some pages.

This happens on pages whose body element has a fixed width with margin: 0 auto. You can work around it with the Stylus extension:

  1. Install Stylus and create a new style for the affected site.
  2. Add the following CSS (adjust the width to match the site): 
    /* Step 1: Remove the width constraint from body. */
body { margin: 0 !important; width: initial !important; }

/* Step 2: Apply the width to the direct children of body. */
header, nav, main, footer {
	margin-left: auto;
	margin-right: auto;
	width: 1080px;
}
Links I opened aren't marked as visited (link color does not change).

This is a change in Google Chrome 136 (April 2025), not a bug in Linkclump Plus. Chrome now partitions visited-link history by site (Partitioned :visited links history), so links that an extension opens may not appear as visited on other pages (their color does not change to the site's visited style).

For background, workarounds, and security considerations, see Notices.

What is Linkclump Plus?

This Linkclump Plus is a fork of linkclump-ng with some fixes and additional features. linkclump-ng is a fork from linkclump and has been updated to Manifest V3.

If you have any issues or feature requests with Linkclump Plus, please report them on GitHub.
